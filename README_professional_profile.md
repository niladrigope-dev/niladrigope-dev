## About

I'm developing the fundamentals to build reliable software and understand the systems beneath it—from web applications and APIs to machine learning, algorithms, and computer architecture.

- **Learn by building:** turn concepts into small, testable projects.
- **Understand the fundamentals:** focus on how and why things work, not just which tools to use.
- **Work in public:** document experiments, solutions, and progress on GitHub.
- **Improve continuously:** revisit code, test assumptions, and learn from mistakes.

> Current principle: fundamentals first, projects as proof, and clear documentation throughout.

## Learning roadmap

<details>
<summary><strong>01 · Programming and web development</strong></summary>

- Python fundamentals and problem solving — CS50P
- JavaScript, asynchronous programming, and browser fundamentals
- React, component design, state, hooks, and forms
- Node.js, REST APIs, authentication, and database integration
- Full Stack Open — building and deploying full-stack applications
- SQL and relational database fundamentals
- Testing, debugging, accessibility, and clean code

</details>

<details>
<summary><strong>02 · Computer science and algorithms</strong></summary>

- Data structures and algorithmic thinking
- Time and space complexity
- Recursion, sorting, searching, graphs, and dynamic programming
- MIT 6.006 — Introduction to Algorithms
- Operating-system, networking, and software-engineering fundamentals
- C++ fundamentals, memory, and performance-aware programming

</details>

<details>
<summary><strong>03 · Mathematics for machine learning</strong></summary>

- Linear algebra: vectors, matrices, transformations, eigenvalues, and decompositions
- MIT 18.06 — Linear Algebra
- MIT 18.065 — Matrix Methods in Data Analysis, Signal Processing, and Machine Learning
- Calculus and multivariable calculus
- Probability, statistics, and optimization
- Connect mathematical ideas to implemented algorithms and experiments

</details>

<details>
<summary><strong>04 · Machine learning and deep learning</strong></summary>

- NumPy, arrays, tensor shapes, broadcasting, and vectorization
- PyTorch tensors, datasets, training loops, loss functions, and optimizers
- Neural-network fundamentals and backpropagation
- Andrej Karpathy's Neural Networks: Zero to Hero
- Training, validation, evaluation, overfitting, and reproducible experiments
- Transformers and the foundations of modern language models
- Later exploration: retrieval-augmented generation (RAG), fine-tuning, and model evaluation

</details>

<details>
<summary><strong>05 · Systems and performance</strong></summary>

- Linux, shell tools, processes, memory, and concurrency
- Networking, HTTP, sockets, and performance profiling
- Computer architecture and how software maps to hardware
- GPU computing concepts and parallel programming
- Later exploration: CUDA, Triton, and AMD GPU software ecosystems where appropriate

</details>
